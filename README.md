# task-management-system

## PROJECT STRUCTURE

--- 1 FRONT END // React.ts and MUI for design

### Components:

1. TaskCard - card with tasks, user can add: task name, description, priority and status
2. DateCard - date picker for task planning
3. WrapperCards - wrapper for task cards
4. Header - navigation with menu and logo
5. Footer - links and contacts
6. Layout - main layout with header and footer

### Pages:

1. HomePage - main page with app description
2. DailyPage - tasks page with filters and statistics
3. InstructionPage - how to use the app
4. ContactsPage - contacts and links

### Features:

1. Add tasks
2. Delete tasks
3. Mark tasks as completed
4. Filter tasks - All, Active, Done
5. localStorage - tasks saved after page reload
6. Responsive design

### Tech Stack:

1. React
2. TypeScript
3. Vite
4. MUI - Material UI
5. React Router
6. localStorage
